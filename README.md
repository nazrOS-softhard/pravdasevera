# Правда Севера — Digital Publishing House

Фронтенд цифрового издательского дома по макету дизайна: медиа,
издательство, типография, архив, маркетплейс и студия для создателей.

**Стек:** React 18 + Vite + TypeScript + React Router. Без UI-фреймворков —
вся стилизация на CSS-переменных (см. `src/styles/tokens.css`).

## Структура

```
src/
  components/   Header, Footer, Photo (плейсхолдер фото), IconTile,
                StatBlock, ServiceCard, ProjectCard, ProductCard,
                ProjectListItem, Icons (набор inline SVG-иконок)
  pages/
    Home        Главная — hero с фото и модулями платформы
    About       О нас — статистика и ценности
    Services    Услуги — фильтр по категориям
    Projects    Проекты — портфолио с фильтрами
    Studio      Студия — инструменты создателя
    Archive     Архив — поиск, статистика, новые поступления
    Market      Маркетплейс — каталог товаров с ценами
    Account     Личный кабинет — мои проекты, статусы, прогресс
    Contacts    Контакты — телефон, почта, карта, соцсети
  styles/       tokens.css — цветовая и типографская система
```

## Дизайн

Тёмная тема (`#0c0c0d`) с кислотно-жёлтым акцентом (`#e9f22c`), жирная
крупная типографика Inter в верхнем регистре — по образцу
предоставленного макета.

**Важно:** фотографии в макете (айсберги, мастерская, архивные снимки)
заменены на стилизованные градиентные плейсхолдеры того же формата и
пропорций — у меня нет доступа к интернету, чтобы подставить реальные
фото. Компонент `Photo` (`src/components/Photo.tsx`) — единственное
место, где это нужно поменять: замените фон на `background-image` с
вашими снимками.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Деплой на Vercel

1. Залейте содержимое архива в новый репозиторий на GitHub (веб-интерфейс
   GitHub → «Add file» → «Upload files» — работает и с телефона).
2. На vercel.com → **New Project** → выберите репозиторий.
3. Framework Preset определится автоматически как **Vite**
   (Build Command: `npm run build`, Output Directory: `dist`).
4. **Deploy** — `vercel.json` уже настроен под client-side роутинг.
